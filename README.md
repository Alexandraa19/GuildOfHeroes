   ###  класс Movies
Метод 1: `ChangeRating(double newRating)`
Что делает: изменяет поле `Rating` — устанавливает новый рейтинг фильма.
Перед изменением проверяет допустимость: если `newRating < 0` или `newRating > 10`,
метод завершается через ранний `return;`, и рейтинг остаётся прежним.
Тип возврата — `void`.
Метод 2: `IsModern()`
Что возвращает: `bool` - `true`, если фильм выпущен в 2000 году или позже,
иначе `false`. Значение вычисляется по текущему состоянию поля `Year`:
`return Year >= 2000;`. Состояние объекта не изменяет

Почему эти действия относятся именно к этому классу:
Рейтинг фильма по смыслу ограничен диапазоном 0…10 -это свойство фильма,
поэтому проверку диапазона логично держать внутри `Movies`, чтобы каждый объект
пользовался ею одинаково. Признак «современный фильм» вычисляется из года выпуска -
это вопрос, на который отвечает сам фильм, а не внешний код. Поэтому `Program.cs`
только поручает действия объекту и печатает результат, а правила остаются в классе
`Movies`

### Ответы на вопросы

**1. Чем отличается запрет внешней записи от проверки допустимого числа? Где проверяются здоровье при создании и его изменение?**
Запрет внешней записи (`private set`) не позволяет внешнему коду вообще менять значение свойства. Но он не проверяет, какое число записывает разрешенный код (внутри класса)
Здоровье проверяется:
- При создании — в конструкторе `Hero` (там задаются границы для `MaxHealth` и `Health`).
- При изменении — в методах `TakeDamage` (не опускает ниже 0) и `Heal` (не поднимает выше `MaxHealth`).

**2. Как `Name = name;` связывает параметр конструктора, `value` и поле `_name`?**
В конструкторе параметр `name` передается в свойство `Name = name;`. Внутри класса свойство `Name` имеет сеттер (`set`), и значение, которое ему передают, автоматически попадает в переменную `value`. Сеттер обрабатывает `value` (убирает пробелы через `Trim()`) и сохраняет результат в закрытое поле `_name`.

**3. Какие значения в проверках показали, что правило `0 <= Health <= MaxHealth` соблюдается?**
- При создании: `new Hero("Проверка нижней границы", -100)` дал `0/100` (нижняя граница), а `new Hero("Проверка верхней границы", 5000)` дал `200/200` (верхняя граница).
- При изменении: после `TakeDamage(5000)` здоровье Александра стало `0`; после `Heal(5000)` здоровье остановилось на `150` (его `MaxHealth`), а не превысило его.

###  Инкапсуляция собственного класса

**Класс и его назначение:**
Класс `Movies` (Фильм). Предназначен для хранения информации о фильме: название, жанр, год выпуска и рейтинг.

**Какие данные защищены и почему:**
Защищены свойства `Name`, `Genre`, `Year` и `Rating`. 
- `Rating` защищен, чтобы внешний код не мог установить рейтинг больше 10 или меньше 0 (чтобы не испортить оценку фильма). 
- `Name` защищено для того, чтобы при создании фильма автоматически удалялись лишние пробелы по краям, а пустые названия заменялись на запасное.

**Какие свойства имеют private set:**
`Name`, `Genre`, `Year`, `Rating`.

**Какое свойство использует закрытое поле:**
Свойство `Name` использует закрытое поле `_name`.

**Что проверяют конструктор и методы:**
- **Конструктор:** проверяет начальный рейтинг. Если передан рейтинг больше `10`, он автоматически устанавливается в `10`. Если меньше `0` — устанавливается в `0`. Также конструктор через свойство `Name` очищает название от пробелов.
- **Метод `ChangeRating`:** проверяет новое значение рейтинга. Если оно выходит за рамки от `0` до `10`, метод просто игнорирует вызов и ничего не меняет.

**Проверки двух объектов и полученные результаты:**
1. Объект `spiderMan` (создан с рейтингом `8.3`). При вызове `spiderMan.ChangeRating(9.1)` рейтинг изменился на `9.1`. При попытке `spiderMan.ChangeRating(-5)` рейтинг остался `9.1` (недопустимое значение было проигнорировано).
2. Объект `scream` (создан с рейтингом `6.6`). При вызове `scream.ChangeRating(7.2)` рейтинг изменился на `7.2`. При попытке `scream.ChangeRating(15)` рейтинг остался `7.2`.
3. Тест конструктора: при создании объекта `new Movies("Плохой фильм", "Тест", 2023, 15.0)` фактический рейтинг сохранился как `10` (сработало ограничение сверху).
4. Тест внешней записи: попытка сделать `spiderMan.Rating = 999;` из `Program.cs` вызвала ошибку компиляции `CS0272` (запись снаружи запрещена).
